# Psyché

Plataforma SaaS de gestão clínica, administrativa, financeira e operacional para psicólogos e clínicas de psicologia.

## Desenvolvimento local

```bash
npm install
npm run db:migrate
npm run dev
```

## Validação

```bash
npm run test:production
```

## Deploy

Consulte o [guia de deploy no Netlify](docs/netlify-deploy.md). Nunca envie `.env`, certificados ou dados clínicos para o repositório.
